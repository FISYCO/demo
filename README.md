# Seavora

Seavora — сервис поиска и бронирования поездок и жилья. В репозитории живут обе стороны, с которыми работает
FISYCO: дизайн-система и продукт, который её применяет.

| Папка | Что это |
|---|---|
| `ui-kit/` | Дизайн-система `@seavora/ui`: компоненты на Chakra UI, у каждого рецепт с осями из макета Figma |
| `apps/web/` | Продукт: поиск, выдача, страница жилья, бронирование, поездки, сообщения, кабинет и кабинет хозяина |
| `src/` | То, что сюда пишут синхронизации библиотек из Figma |

## Как устроен ui-kit

Компонент — папка из трёх файлов: `Button.tsx`, рецепт `Button.recipe.ts` и `index.ts`. Оси рецепта называются
так же, как оси набора в Figma (`size`, `variant`), а значения совпадают по написанию (`sm`, `outline`). Палитра —
проп `colorPalette`. Составные компоненты — пространства имён из частей: `Card.Root`, `Card.Body`, `Tabs.Trigger`.
Тема собирается в `ui-kit/theme.ts`.

## Что расходится с макетом

Дизайн-система живая, и код отстаёт от макета так же, как у любой команды:

- у `Button` нет размера `2xs`, который есть в макете;
- у `Separator` нет варианта `dotted`;
- у `Card` радиус `l2`, в макете — `l3`; зато в коде есть вариант `interactive`, которого в макете нет;
- в макете уже есть Carousel, ColorPicker, Combobox, QRCode, TagsInput и TreeView — в код они ещё не пришли;
- в продукте остались свои решения мимо системы: `PriceTag` и `PromoBanner` с цветами числами и инлайновой
  иконкой, `OldModal` вместо `Dialog` в удалении аккаунта.
