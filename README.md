# FISYCO demo

Демонстрационный репозиторий. Здесь одновременно живут обе стороны, с которыми работает FISYCO.

## Что где лежит

| Папка | Что это |
|---|---|
| `ui-kit/` | Дизайн-система: 36 компонентов на React и токены. То, что библиотекарь читает и сверяет с макетом |
| `apps/web/` | Продукт, который применяет дизайн-систему. Из него собирается граф употребления |
| `src/assets/` | Иконки и иллюстрации, которые пишет сюда синхронизация из Figma |
| `src/tokens/` | Токены, которые пишет сюда синхронизация из Figma |

Первые две папки — вход библиотекаря, вторые две — выход библиотек. Репозиторий и читают, и пишут,
и это нормальный случай, а не исключение.

## Что здесь оставлено намеренно

Репозиторий нужен для проверки продукта, поэтому в нём есть то, что продукт должен находить.

- **`Btn` вместо `Button`.** Имя повторяет имя набора в Figma: связка «макет ↔ код» выводится
  заново при каждой индексации, и совпадающее имя — самый сильный её сигнал.
- **Нет размера `xs`.** В макете он есть, в коде — нет, а `apps/web/src/pages/Checkout.tsx` его
  всё равно вызывает. Это структурное расхождение, и оно должно быть видно.
- **Нет состояния `focus`.** В макете есть, в коде не выражено.
- **`LegacyModal`** — своя модалка вместо `Dialog` из библиотеки.
- **`BrandBanner`** — цвета числами мимо токенов и инлайновая иконка вместо библиотечной.
- **`Tooltip`** помечен устаревшим с указанием замены.

Ничего из этого чинить не нужно: на этом проверяется, что библиотекарь видит то, что должен.

## Что добавлено для объёма анализа

Чтобы у библиотекаря было на чём работать, продукт расширен до девяти экранов и трёх десятков
составных блоков, а дизайн-система — до 36 компонентов. Часть добавленного — намеренные обходы.

- **Оси вариантов**: у новых компонентов по 1–3 оси (`size`, `tone`, `variant`, `placement`), и
  часть значений в продукте не используется — например `Drawer size="full"`, `Progress shape="ring"`,
  `Toast placement="bottom-center"` встречается один раз, `Chip tone="warning"` — редко.
- **Устаревшее с заменой**: `List` (→ `Table`), `Popover` (→ `Menu` / `Drawer`), `Tooltip` (→ `Popover`).
  Все три продолжают применяться в продукте.
- **Дубль**: `ui-kit/legacy/Badge.tsx` объявляет второй `Badge`.
- **Обёртки**: `IconButton` на `forwardRef`, `Skeleton` на `memo`, `Menu` — пространство имён
  `Menu.Root` / `Menu.Item` / `Menu.Separator`.
- **Свои компоненты вместо библиотечных**: `OldButton`, `LegacyTable`, `CustomTooltip`,
  `AdHocModal`, `StatusDot`, `HeroBanner`, `IconTile`, `ReportChart` в `apps/web/src/components/legacy/`.
- **Цвета мимо токенов**: hex, `rgba()` и `hsl()` в старых компонентах и в самой дизайн-системе
  (`Alert`, `Badge`, `Chip`, `Toast`).
- **Сырые токены шкалы**: `apps/web/src/lib/legacy-palette.ts` (`gray.500`, `blue.600`) и
  `LegacyTable`.
- **Иконки**: инлайновые `<svg>` в `HeroBanner`, `CustomTooltip`, `ReportChart`; картинкой —
  `IconTile` (`<img src="/icons/*.svg">`); внешняя картинка по URL — `HeroBanner`. Иконки из
  библиотеки применяются как компоненты (`Bell`, `Search` из `src/assets/icons`).
