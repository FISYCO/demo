# FISYCO demo

Демонстрационный репозиторий. Здесь одновременно живут обе стороны, с которыми работает FISYCO.

## Что где лежит

| Папка | Что это |
|---|---|
| `ui-kit/` | Дизайн-система: 17 компонентов на React и токены. То, что библиотекарь читает и сверяет с макетом |
| `apps/web/` | Продукт, который применяет дизайн-систему. Из него собирается граф употребления |
| `src/assets/` | Иконки и иллюстрации, которые пишет сюда синхронизация из Figma |
| `src/tokens/` | Токены, которые пишет сюда синхронизация из Figma |

Первые две папки — вход библиотекаря, вторые две — выход библиотек. Репозиторий и читают, и пишут,
и это нормальный случай, а не исключение.

## Что здесь оставлено намеренно

Репозиторий нужен для проверки продукта, поэтому в нём есть то, что продукт должен находить.

- **`Btn` вместо `Button`.** Имя повторяет имя набора в Figma: связка «макет ↔ код» выводится
  заново при каждой индексации, и совпадающее имя — самый сильный её сигнал.
- **Нет размера `xs`.** В макете он есть, в коде — нет, а `apps/web/src/pages/Checkout.tsx` его
  всё равно вызывает. Это структурное расхождение, и оно должно быть видно.
- **Нет состояния `focus`.** В макете есть, в коде не выражено.
- **`LegacyModal`** — своя модалка вместо `Dialog` из библиотеки.
- **`BrandBanner`** — цвета числами мимо токенов и инлайновая иконка вместо библиотечной.
- **`Tooltip`** помечен устаревшим с указанием замены.

Ничего из этого чинить не нужно: на этом проверяется, что библиотекарь видит то, что должен.
